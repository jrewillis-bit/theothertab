# The Other Tab

A personal Jekyll blog. Enable Settings > Pages > Deploy from a branch > main > / (root).

## Publish
Create `_posts/YYYY-MM-DD-title.md` using the example in `_drafts/example.md`. Use one category (Technology, Minimalism, Gaming, Teaching or Life), a description and optional tags. Commit to main. Drafts are not published. Edit `_config.yml` when moving to a custom domain. No analytics, cookies or external fonts.
