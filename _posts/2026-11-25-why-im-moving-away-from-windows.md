*From SUSE Linux 7.3 on a 100MHz Pentium to Linux Mint on a second-hand ThinkPad.*

I've been using Linux on and off since I was 12. My first experience was with SUSE Linux 7.3, installed on an old 100MHz Pentium PC. It wasn't exactly a powerful machine, and installing an operating system on it was a rather different proposition to what we're used to today.

SUSE came on seven CDs or a single DVD. Installation seemed to take forever. There was a fair amount of waiting involved, and getting the operating system installed was only part of the challenge. Linux was something you experimented with rather than something you necessarily expected to replace Windows overnight.

I remember the arrival of Ubuntu in 2004 and the change it represented for desktop Linux. I even joined a Linux User Group in Wolverhampton. In an era before today's abundance of tutorials and online communities, meeting other people who were interested in Linux was a great way to learn and share ideas.

Windows, of course, remained a significant part of my computing life. It was the operating system I encountered throughout education and employment, and as a Computer Science teacher I still work in an environment where Microsoft software is firmly established.

But Linux has always been there in the background.

What's interesting is that my reasons for using it have changed. At 12, part of the appeal was the challenge of getting something different working. Today, I increasingly use Linux because I want less hassle, not more.

## When Windows stopped feeling like just an operating system

There is a lot to like about Windows. It has excellent software compatibility, extensive hardware support and a familiar interface. It has also served me well for a considerable part of my life.

My frustration is less about what Windows can do and more about what it increasingly wants to do.

Microsoft account prompts, OneDrive integration, recommendations, Copilot and the promotion of other Microsoft services all compete for a little bit of attention. Many of those features can be adjusted, removed or ignored, but that in itself takes time.

Some people genuinely benefit from the integration. If you use Microsoft 365 across several computers, for example, OneDrive can be an incredibly convenient way of keeping files accessible. I don't object to those services existing. I object to the assumption that I necessarily want them all as part of my operating system.

When I switch on a computer, I want to open the applications I need and get on with whatever I was intending to do.

I don't particularly want my desktop to be a shop window for subscriptions. Nor do I want every part of my digital life tied to a particular company.

There is an irony in comparing Windows with Linux here. In the early 2000s, Linux was often the operating system that required more configuration before you could get on with your work. These days, I find myself questioning how much unnecessary configuration I have to do in Windows instead.

## Why Linux Mint?

I've settled on [Linux Mint](https://linuxmint.com/) because it doesn't try to reinvent the desktop.

The Cinnamon desktop has a familiar application menu, taskbar, system tray and file manager. If you've spent years using Windows, most of it will feel remarkably intuitive.

There is a graphical Software Manager for installing applications, an Update Manager for maintaining the system and Timeshift for taking system snapshots. You can use the terminal if you want to, but you don't need to spend every evening typing commands to keep the computer working.

That matters to me. I teach Computer Science and enjoy understanding how technology works, but that doesn't mean I want every piece of technology I own to become another project.

Sometimes I just want to sit down and write an article, check an email or develop a website.

A modern Mint installation also illustrates how far Linux has come since those seven SUSE CDs. You can download the operating system, write it to a USB drive and try a live desktop before committing to an installation. It is worth checking hardware compatibility, but there is considerably less friction involved than I remember from my early experiences.

## A £235 computer that does what I need

My current laptop is a second-hand Lenovo ThinkPad T14s Gen 2. It cost me £235 and has an AMD Ryzen 5 processor, 16GB of RAM and a 500GB SSD.

I've written separately about [why buying that ThinkPad made more sense to me than buying a new laptop](/articles/my-235-thinkpad-running-linux-mint/).

It is a good match for Linux Mint. I have a perfectly capable machine for browsing, writing, programming, developing websites and everyday productivity, without needing to spend hundreds of pounds more on something new.

I also own a Beelink Mini S12, another example of how relatively modest hardware can be useful for everyday computing. There is little sense in measuring the value of either machine against the latest hardware if they already meet my needs.

The conversation around Windows 11 hardware requirements has made this particularly relevant. Official Windows 11 support depends on a range of requirements, including a compatible processor, TPM 2.0 and UEFI firmware capable of Secure Boot. Some otherwise useful computers fall outside those requirements.

Linux doesn't make an old processor faster or repair a failing battery. It does, however, offer another route for keeping compatible hardware useful and receiving security updates through a supported distribution.

Before replacing a computer, I think it's worth asking whether the hardware has actually become inadequate or whether the software expectations have changed.

## How much of my computing actually needs Windows?

This is probably the most important question for anyone considering a move to Linux.

Take an ordinary week and think about what you actually use your computer for. Not the things you might theoretically want to do in the future, but the tasks you routinely complete.

For me, that includes browsing, email, writing, working with documents, programming, creating websites, managing online services and accessing files stored on my home network.

A remarkable proportion of that now happens inside a browser.

Microsoft 365, Outlook, Teams, SharePoint, Canva and GitHub are all accessible through the web. There are differences between browser-based and desktop applications, but many of the tasks I need to complete don't require Windows at all.

That was not always the case. When I first started experimenting with Linux, replacing Windows could mean finding alternatives to almost every application you used. These days, many of those applications are already platform-independent.

Moving to Linux doesn't mean I have to abandon Microsoft services, either. I can continue using them where they make sense without necessarily running Microsoft's operating system.

## The biggest compromise: Microsoft Office

As a teacher, this is the area where things become more complicated.

I regularly work with Word documents, PowerPoint presentations and Excel spreadsheets. They are deeply embedded in education, and simply deciding to use a different file format is not a particularly practical option when those files need to be shared with colleagues and students.

The full desktop Microsoft Office applications don't run natively on Linux. Instead, there are three particularly useful options.

[LibreOffice](https://www.libreoffice.org/) is a free, open-source office suite that provides Writer, Calc and Impress, amongst other tools. It can open and save common Microsoft Office formats, although its native document format is OpenDocument.

[ONLYOFFICE](https://www.onlyoffice.com/) offers a more familiar Microsoft Office-style interface and focuses on working with formats such as DOCX, XLSX and PPTX.

Then there is [Microsoft 365 on the web](https://www.microsoft365.com/). Provided you have the appropriate account and access, you can use browser versions of Word, Excel and PowerPoint directly.

For many ordinary documents and presentations, these are perfectly reasonable alternatives. However, complex formatting, unusual fonts, advanced Excel macros, PowerPoint animations and other specialist features can cause problems.

Opening an important presentation in another office suite is one thing. Discovering that its layout has changed just as you're about to deliver a lesson is quite another.

My approach is to be pragmatic. Use Linux-compatible tools for the tasks they handle well, test important files before sharing them and retain access to Windows where genuine desktop Office compatibility is essential.

There is no point turning a straightforward task into a complicated one just to avoid a particular operating system.

## What software can I still run?

The range of software available for Linux is considerably better than it was when I first started using it.

Some applications run natively, others are available through the web, and some have entirely different alternatives. The following are examples of what is available, rather than a claim that every application is installed on my own computer.

| Task | Native Linux applications or browser alternatives |
|---|---|
| Web browsing | Firefox, Chrome, Brave, Edge |
| Documents and spreadsheets | LibreOffice, ONLYOFFICE, Microsoft 365 online |
| Email | Thunderbird, Outlook online |
| Programming | Python, Visual Studio Code, Thonny |
| Website development | Git, VS Code, Node.js |
| Image editing | GIMP, Krita, Photopea (web) |
| Vector graphics | Inkscape |
| Video editing | Kdenlive, Shotcut |
| Audio editing | Audacity |
| Media playback | VLC, Jellyfin through a browser |
| Password management | Bitwarden, KeePassXC |
| PDF organisation | PDF Arranger, LibreOffice Draw |
| Gaming | Steam and Proton |
| Remote access | Remmina, SSH |
| Local file transfers | LocalSend, KDE Connect |

Some of the familiar applications you use on Windows are also available on Linux. Others are not direct replacements. GIMP, for instance, is a capable image editor, but someone with an established Adobe Photoshop workflow may find the differences significant.

The right way to approach this is to think about the task rather than the application. If I need to crop an image, edit a photograph or create a simple graphic, I don't necessarily need a particular piece of commercial software to do it.

## Programming and web development

One area where Linux feels particularly natural is programming.

Python is readily available, Visual Studio Code runs natively, and Git and SSH can be used directly from the terminal. Projects involving HTML, CSS, JavaScript and Node.js can all be developed on Linux.

As a Computer Science teacher, I spend time developing resources and building web-based tools for students. The operating system really doesn't matter much to the end user of a website. They just need a browser.

[The Other Tab itself runs on GitHub Pages](/articles/building-a-personal-blog-for-the-price-of-a-domain-name/), which means I don't need Windows-specific software to manage or publish the site.

Linux also offers a useful environment for learning how software is installed and managed, how processes work, how permissions are applied and how network services communicate. These are concepts I teach, and having a working example of them on my own computer is useful.

There is a distinction, though, between enjoying the flexibility of the terminal and being forced to use it for ordinary tasks. Linux Mint gives me the option of using it when it is the most sensible tool.

## My files don't have to live in OneDrive

Another part of my move towards Linux has been made easier by changes to the way I store my files.

I have a UGREEN NASync DXP2800 that I use for network storage, automatic mobile phone photo backups and services such as Jellyfin and AdGuard. It also syncs data to Backblaze for off-site storage.

I've covered that setup in more detail in [My own little cloud](/articles/my-own-little-cloud-ugreen-nasync-dxp2800/).

The advantage is that my data isn't tied to one computer or operating system. I can access ordinary network shares from Mint's file manager, and many of my services are accessible through a browser.

I still use cloud services when they make sense. Backblaze is a good example. I just prefer to choose the service rather than feel that it is the inevitable consequence of using a particular operating system.

This isn't a requirement for moving to Linux. Plenty of people will be happy using their existing cloud storage. It simply fits particularly well with the way my own computing setup has evolved.

## Installing software is a little different

On Windows, installing a program often involves searching for its website, downloading an installer and clicking through several screens.

Linux Mint encourages you to start with the Software Manager instead. It provides a graphical way to discover and install applications, with many updates handled through the system's package management tools.

There are a few terms worth getting to grips with:

- **APT packages:** Software installed from traditional package repositories. Updates are managed through the package manager.
- **Flatpak:** A format for distributing applications across different Linux distributions, with isolation and separately managed runtimes.
- **AppImage:** A portable application format. Often you download the file, make it executable and run it, rather than installing it conventionally.
- **DEB packages:** Downloadable installation packages compatible with Debian-based distributions such as the main edition of Linux Mint.

Initially, the number of formats can seem unnecessarily complicated. Occasionally an application is available through more than one route, and the versions or permissions may differ.

For ordinary use, my advice would be to start with the Software Manager and only look elsewhere when there is a particular reason to do so. Stick to trustworthy sources, just as you should when downloading software for Windows.

Updates are another adjustment. Mint lets you review and install available updates through the Update Manager. That doesn't mean you should ignore them. Keeping a Linux system supported and up to date is every bit as important as maintaining Windows.

Timeshift is also useful for system recovery, but its default system snapshots are not a substitute for backing up personal files.

## Gaming and the remaining limitations

Gaming was once one of the clearest reasons to stay with Windows.

Steam's Proton compatibility layer has changed the situation considerably, allowing many Windows games to run on Linux. Native Linux games are also available.

That doesn't mean every game works. Some multiplayer games with particular anti-cheat systems remain incompatible, and others may need adjustments. Before moving, it is worth checking the specific games you actually play on [ProtonDB](https://www.protondb.com/).

There are similar considerations for specialist software. Adobe's desktop Creative Cloud applications, certain professional engineering tools and some proprietary hardware utilities may still require Windows or macOS. Wine and other compatibility tools can be useful, but they are not guaranteed solutions.

Peripheral compatibility matters too. A live USB session is a good opportunity to test Wi-Fi, Bluetooth, sound, external displays and any specialist equipment before installing.

This is particularly relevant in schools. I've considered moving my school desktop to Linux, but it is a more complicated proposition than using Linux on a personal laptop. School authentication, central device management, PaperCut printing and Microsoft 365 all need to be considered. It also needs to be supported by the organisation's IT arrangements.

A computer has to work within the environment it is being used in. At home I can choose my own workflow; at work there are good reasons for maintaining compatibility and following organisational policies.

## I'm not trying to become completely Windows-free

The word *gradually* in the title is deliberate.

I don't see this as a competition to see how quickly I can remove every trace of Microsoft from my life. Windows still has its place, and I have no issue using it when it is genuinely the most appropriate tool.

A gradual migration also avoids creating problems unnecessarily. Start by moving to applications that are available on both platforms. Get used to an alternative office suite, if it meets your requirements. Store files in formats and locations that can be accessed independently of the operating system.

When you're ready to try Linux, use a spare computer or boot from a USB drive. Make a proper backup before installing, check that your important hardware works and give yourself time to adjust. Keeping access to Windows during the transition can be a useful safety net.

The aim is not to be able to say that I never use Windows. It is to stop assuming that I need it for everything.

## Coming full circle

When I think back to that old 100MHz Pentium and the seven SUSE CDs, I'm struck by how much has changed.

The idea that a free, community-developed operating system could become my preferred environment for everyday work would probably have seemed quite ambitious at the time. I was fascinated by Linux partly because it was different and partly because I wanted to understand it.

Today, it is the ordinary things that make Linux appealing. I can open a browser, write something, develop a website, access my files and get on with my day.

There is still plenty to learn if I want to experiment. But the computer doesn't demand that I make an evening of it.

My gradual move away from Windows fits with other changes I've made in my relationship with technology: buying second-hand hardware, using open-source software, running my own services and questioning whether I really need the latest product or another subscription.

None of these choices requires rejecting commercial software entirely. It is more about having a choice in the first place.

More than two decades after installing SUSE Linux 7.3, I find myself increasingly drawn to Linux for a reason that my 12-year-old self might not have expected.

Back then, I used Linux because I enjoyed the challenge.

Today, I use Linux because I increasingly want my technology to get out of the way.
